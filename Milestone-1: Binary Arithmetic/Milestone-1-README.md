# Milestone 1: Binary Arithmetic

The first major milestone for me would be to develop the circuits the 4 basic arithmetic processes: addition, subtraction, division, and multiplication. 
This is the first major milestone in my mind that shows the biggest progress towards a fully working ALU.

As I complete parts of this milestone, I will create new subfolders within this folder Milestone 1 folder that have their own README.md files along with the .circ files for the actual circuit itself for people that want to download the files to test it on their own device. For those of you who don't want to download the files and open it on your devices I will add Screenshots of all the circuits and subcircuits at the bottom of the README files within the subfolders. There will also be a Screenshots folder inside the subfolder to keep all the screenshots consolidated in one place. With the README.md file having in depth explanations on what circuit I made, how I made it, and what setbacks I faced while building it. I will also make it detailed enough that it will be readable for someone with little to none expeirence and knowledge in logic gate circuits or computer logic systems.
