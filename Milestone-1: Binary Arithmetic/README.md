# Milestone 1: Binary Arithmetic
---
The first major milestone for me would be to develop the circuits the 4 basic arithmetic processes: addition, subtraction, division, and multiplication. 
This is the first major milestone in my mind that shows the biggest progress towards a fully working ALU.

As I complete parts of this milestone, I will create new subfolders within this folder Milestone 1 folder that have their own README.md files along with the .circ files for the actual circuit itself. With the README.md file having in depth explanations on what circuit I made, how I made it, and what setbacks I faced while building it. I will also make it detailed enough that it will be readable for someone with little to none expeirence and knowledge in logic gate circuits or computer logic systems.
