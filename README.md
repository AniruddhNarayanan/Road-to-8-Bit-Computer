# Road-to-8-Bit-Computer
Building a simple 8-Bit Computer step by step from simple logic gates. 

This project is a personal project that I am doing since i am very intrigued by computer logic on the lowest level of logic gates. Due to that I am making this projcet to document every step of my journey to making a full 8-bit computer with every part of the project built by me using my research and understanding of logic gates and logic systems. 
It will start off with the simple logic gate circuits that make up an ALU (Arithmetic Logic Unit) and then building working memory, and then the logic systems architectures that go into the processor. 
My goal is to document my journey as I explore how a full computer system works at the small scale of 8-bits. 

The Project Objectives and plan are as follows:
 - Work on arithmitic logic circuits using logic gates
 - Combine the arithmatic circuits into a fully functioning ALU
 - Understand how sequential logic, registers, and memory works
 - Understand and build a control unit or the brain of the computer that can send and execute instructions
 - Make custom instructions and implement it
 - Integrate all the componets into a functioning 8-bit computer


My planned roadmap:
1. Binary Arithmetic Calculator
2. 8-bit ALU
3. Registers and Sequential Logic
4. RAM and ROM
5. Instruction Set and Architecture
6. Control Unit
7. Put everything together into the 8-Bit Computer

I will be using Logisim Evolution to design the digital logic circuits and the simulation of the circuits.
